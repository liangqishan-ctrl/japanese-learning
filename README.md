# Japanese Learning · 四季日语听力练习

四季，每季30期、每期5题，共120期、600道原创基础日语听力题。

- 第一季：基础起步。
- 第二季：基础强化，辨别改口、时间、数量与否定。
- 第三季：细节巩固，连接人物、地点与行动顺序。
- 第四季：场景应用，在日常短对话中找出需要的信息。

## 使用

打开网站，在页面上方选择季数，再选择课程。每题先点播放听力，然后选择 A、B、C、D。选择后立即显示正确答案与中文依据。五题完成后显示百分制分数，每题20分，首次选择计分。

支持日语语音选择、0.75/0.9/1倍语速、复制原文、展开原文、错题复习。各季作答记录分别保存在当前浏览器。不同网址、设备或浏览器之间不会自动同步。

手机无声时，先关闭静音模式，检查媒体音量和蓝牙输出，再使用页面中的测试手机声音与日语试音。朗读使用设备提供的日语合成语音，音色由设备决定。

## GitHub Pages

本仓库的 index.html 包含全部界面、脚本、题库和测试音，无须构建、安装依赖或配置密钥。

在仓库 Settings → Pages 中，选择 Deploy from a branch，选择 main 分支和 / (root)，保存即可。网站发布后，无需登录便可使用。

网址后加 ?season=1、?season=2、?season=3 或 ?season=4，可直接打开指定季。未指定时继续当前浏览器保存的季数；首次默认第三季。

## 内容说明

课程以基础日语和日常慢速短对话为目标设计，不是官方真题或官方等级认证。课程成绩不等于考试成绩。程序无需账户，不上传练习成绩，不包含任何用户名、密码、访问令牌或私有账户数据。
